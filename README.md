# 💧 AquaCatch – Water Bottle Catching Game

A fun and interactive browser-based game where players control a water bottle holder to catch falling bottles before they reach the bottom and spill.

Built with HTML, CSS, and JavaScript, AquaCatch challenges players to score as high as possible while avoiding missed bottles and water splashes.

---

## 📌 Project Overview

**AquaCatch** is a browser-based game developed using HTML5, CSS3, and JavaScript. The player moves a bottle holder left and right to catch falling water bottles. If a bottle reaches the bottom, it spills and creates a splash effect.

The game includes a score counter, best score tracking, a countdown timer, and a game-over screen with a **Play Again** option. It works on both desktop (mouse) and mobile (touch/tap) devices.

This project is suitable for a college academic project, GitHub portfolio, and resume project showcase.

## 🕹️ How to Play

1. Open the game in a web browser.
2. Move the bottle holder left and right.
3. Catch the falling bottles before they reach the bottom.
4. Avoid missing bottles, as missed bottles spill and create a splash.
5. Try to score as high as possible before the timer runs out.
6. When the game ends, click **Play Again** to restart.
